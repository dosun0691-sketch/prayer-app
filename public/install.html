기도 달성표 설치하기

휴대폰 종류에 맞는 안내를 따라 주세요. 어느 쪽으로 설치해도 같은 기록을 함께 봅니다.

안드로이드 (삼성 등)

앱 파일 받아서 설치

  1. 아래 앱 다운로드 버튼을 누릅니다.
  2. 다운로드가 끝나면 알림이나 ‘내 파일 → 다운로드’에서 prayer-app.apk를 누릅니다.
  3. ‘이 출처의 앱 설치 허용’ 화면이 나오면 허용을 켜고 뒤로 돌아옵니다. (처음 한 번만)
  4. 설치를 누릅니다. 홈 화면에 ‘기도 달성표’ 아이콘이 생깁니다.
앱 다운로드 (약 1MB)

Play 스토어 앱이 아니어서 ‘알 수 없는 앱’ 경고가 뜰 수 있습니다. 우리 교회에서 만든 앱입니다. 안드로이드 7.0 이상에서 됩니다.

아이폰

홈 화면에 추가

  1. Safari로 아래 버튼을 엽니다. (카카오톡·LINE 안에서 열렸다면 메뉴에서 ‘Safari로 열기’)
  2. 아래쪽 가운데 공유 버튼(네모에서 위로 화살표)을 누릅니다.
  3. 목록을 내려 ‘홈 화면에 추가’를 누르고, 오른쪽 위 추가를 누릅니다.
  4. 홈 화면의 ‘기도 달성표’ 아이콘으로 앱처럼 엽니다.

安裝禱告達成表

請依照你的手機種類操作。不論用哪一種方式安裝，大家看到的都是同一份紀錄。

Android（三星等）

下載App檔案安裝

  1. 按下方的下載App按鈕。
  2. 下載完成後，在通知或「我的檔案 → 下載」中點選 prayer-app.apk。
  3. 出現「允許安裝此來源的應用程式」時，請開啟允許，再返回。（只需第一次）
  4. 按安裝。主畫面會出現「기도 달성표」圖示。
下載App（約1MB）

這不是 Play 商店的 App，可能會出現「未知的應用程式」警告。這是我們教會自己做的 App。Android 7.0 以上可以使用。

iPhone

加入主畫面

  1. 用 Safari 打開下方按鈕。（如果是在 LINE 裡打開，請從選單選「用 Safari 開啟」）
  2. 按下方中間的分享按鈕（方框加向上箭頭）。
  3. 往下滑，按「加入主畫面」，再按右上角的新增。
  4. 之後從主畫面的圖示打開，就像 App 一樣使用。
